# Rose 🌹 | A Little World Made For You

A modern, cinematic, and responsive digital love story and relationship tribute created for **Rose**. Built with Next.js 16 (App Router), React 19, Tailwind CSS, Three.js 3D scenes, Framer Motion, and multimedia vaults.

---

## ✨ Features

- **🌹 Luxury Rose Aesthetic**: Tailored bespoke design with blooming rose insignia, rich warm color palettes, and glassmorphism.
- **📸 Hanging Polaroid Clothesline**: Dynamic clothesline of swaying polaroid memories with soft ambient illumination, unclipped photos, and one-word tags.
- **🌌 Immersive 3D Love Universe**: Real-time Three.js scene featuring floating glowing hearts, crescent moon, dreamy clouds, twinkling stars, and interactive wishes.
- **📜 Our Little Story Timeline**: Staggered interactive relationship timeline with memory cards, custom polaroid snapshots, and date markers.
- **🖼️ Full-Bleed Memory Carousel**: Horizontal snap carousel displaying all 37 photo snapshots of Rose with category filters (*Smiles*, *Favorites*, *Moments*, *Places*) and fullscreen lightbox.
- **🪐 3D Floating Scrapbook Wall**: Interactive 3D tilt stage allowing mouse and touch exploration of floating polaroid depth.
- **💌 Things I Love About You**: 6 interactive love cards with photo thumbnails and intimate love reflections.
- **❤️ Interactive Tap the Heart**: Pulsing interactive heart that bursts with confetti and reveals progressive photos and messages on each tap.
- **🌅 Golden Sunset Wishes**: Poetic staggered reveal with warm gradient lighting.
- **🎬 Rose's Video Vault**: Mobile-responsive 9:16 reel player featuring 5 video reels with audio toggle, ambient backdrops, and playback controls.
- **✍️ Dedicated Animated Shayaris**: 6 original Hindi/English Shayaris written specifically for Rose, with photo cards, copy-to-clipboard, and mood badges.
- **🎵 Melody Player & Cinema Watchlist**: Bollywood & Sanam romantic songs with embedded YouTube playback, plus a cozy date-night movie watchlist.
- **📬 Living Memory Vault**: Cloud-backed love capsule with message submission and photo upload support via MongoDB Atlas and ImageKit.
- **💌 Wax-Sealed Opening Letter**: Interactive seal that breaks open with a smooth slide-out handwritten letter.
- **📌 Memory Board Scrapbook**: Scattered polaroid collage with colorful washi tape and hover straightening.
- **⭐ Starlit Constellation Sky**: Night sky with clickable twinkling stars revealing secret wishes.
- **⏳ Relationship Memory Timer**: Live ticking relationship counter tracking 823 days of love and cherished moments.
- **🎉 Final Surprise Explosion**: Multi-angle confetti celebration with a glowing heart portrait.
- **📱 Fully Responsive**: Fluid full-width design tailored for widescreen laptops, desktops, tablets, and phones.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **Frontend**: [React 19](https://react.dev/), TypeScript
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **3D Graphics**: [Three.js](https://threejs.org/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/), [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Database (Optional)**: [MongoDB Atlas](https://www.mongodb.com/atlas)
- **Media CDN (Optional)**: [ImageKit.io](https://imagekit.io/)

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/exobunix/shinn.git
cd shinn
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Environment Variables (Optional)
Copy `.env.example` to `.env.local` and add your database and ImageKit credentials if using the notes wall:
```bash
cp .env.example .env.local
```

### 4. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the website.
